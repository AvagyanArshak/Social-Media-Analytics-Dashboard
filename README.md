# 📊 Social Media Analytics 

## 📌 About the Project
Social media data analysis using Power BI.
The dataset contains 12,000 records from 5 platforms:
Facebook, Instagram, Twitter, YouTube, and Reddit.

## 📁 Files
| File | Description |
|---|---|
| `Social_Media_Analytics.pbix` | Power BI Dashboard |
| `Social_Media_Analytics.xlsx` | Excel Data |
| `Social_Media_Engagement_Dataset.csv` | Raw Dataset |

## 📊 Dashboard Structure

### Page 1 — Social Media Analytics
- KPI Cards — Total Likes (30M), Comments (6M), Shares (12M), Avg Engagement (0.28)
- Line Chart — Engagement Rate by Month
- Bar Chart — Likes by Platform
- Pie Chart — Sentiment Distribution
- Slicer — Platform Filter

### Page 2 — Brand & Campaign
- Bar Chart — Likes by Brand
- Bar Chart — Impressions by Campaign
- Line Chart — Buzz Change Rate by Month
- Table — Campaign Performance (campaign_phase, engagement_rate)
- Slicer — Brand Filter

### Page 3 — Sentiment & Emotion
- Pie Chart — Sentiment Distribution (Positive/Negative/Neutral)
- Bar Chart — Posts by Emotion Type
- Line Chart — Sentiment Score by Month
- Slicer — Sentiment Filter

### Page 4 — Location & Language
- Bar Chart — Likes by Location
- Bar Chart — Engagement Rate by Location
- Pie Chart — Posts by Language
- Slicer — Language Filter

## 🛠️ Tools Used
- **Power BI Desktop** — Dashboard development
- **CSV/Excel** — Data sources

## 📈 Key Insights
- 🏆 **Samsung** leads in total Likes
- 📅 **November** shows a sharp spike in Buzz Change Rate
- 🌍 **Rio de Janeiro** has the highest Engagement Rate
- 😊 **Positive** and **Negative** sentiments are nearly equal (~40%)
- 🏅 **CustomerFirst Post-Launch** campaign has the highest engagement (0.38)
